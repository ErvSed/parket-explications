# Паркет в экспликациях полов — сводка по объектам

Интерактивный отчёт по типам полов с паркетом (и его имитацией), выбранным из «Экспликаций полов»
раздела АР2 по объектам культурного наследия:

- «Дворец» — захватки 1.1, 1.3, 1.4, 2;
- «Манеж»;
- «Конюшни главные дворцовые»;
- «Корпус служебный».

Объект: г. Санкт-Петербург, пл. Труда, д. 4, литера В — «Дворец Великого князя Николая Николаевича
(Ксенинский институт)».

## Что внутри

`index.html` — отчёт. Секции по корпусам и захваткам, внутри — три группы типов полов:

- **предмет охраны** — «Восстанавливаемый паркет на клею под лаком — см. том
  НД-2026-1-Р-1.1/1.3/1.4/2-РР.АИ — 15+3 мм»;
- **новодельный паркет** — новый паркет «ёлка» на фанере / дощатом настиле;
- **имитация паркета** — керамогранитная плитка с раскладкой под исторический рисунок паркета.

При наведении на тип пола открывается скриншот строки экспликации: номер помещения, тип пола,
схема пола (разрез конструкции), описание слоёв, площадь, примечание. Над скриншотом — шифр тома
и номер листа. Клик по скриншоту — увеличение.

`img/` — те же скриншоты отдельными файлами PNG.

### Пирог пола при наведении

Наведите курсор на тип пола — открывается карточка «Пирог пола»:

- слева — увеличенная схема пола из экспликации (разрез конструкции со всеми слоями и проставленными
  толщинами), со шифром тома и номером листа;
- справа — полный список слоёв с номерами, толщинами и цветовой маркировкой материала
  (паркет, плитка, стяжка, гидроизоляция, утеплитель, бетон, дерево, существующие конструкции);
- ниже — примечание к типу пола и площадь.

Клик по карточке открывает полный фрагмент экспликации (строка таблицы целиком) в лайтбоксе.
Если в строке стоит «см. тип N» (схема не вычерчена), показывается схема указанного типа с пометкой.

`img/` — скриншоты строк экспликации, `img/schema/` — схемы пола крупным планом.

## Примечания

- Восстановление паркета предусмотрено только во «Дворце» (все 4 захватки). В «Манеже»,
  «Конюшнях» и «Корпусе служебном» восстанавливаемого паркета нет — только новодел.
- В «Манеже» паркет идёт по «Экспликации перекрытий», а не по «Экспликации полов».
- Конюшни: типы 1 и 2 — паркет «ёлка» 300×90 «по историческому образцу» (отдельный лист раскладки
  приведён в отчёте), но сам паркет новодельный. Тип 10 — инженерная доска, в список не включён.
- В томе Захватка 1.3 номера помещений в таблице «Общая экспликация полов тома» не приводятся.
- Два тома по Конюшням (исходный и Изм. 2 от 07.10.2026) по паркету идентичны.
- Площади — по графе «Площадь» экспликации, без пересчёта.

## Источник

9 PDF-томов раздела «Архитектурные решения» (АР2), суммарно 275 листов.
Отчёт сформирован автоматически: таблицы экспликаций восстановлены по геометрии листов
(PyMuPDF), строки привязаны к типам пола, скриншоты вырезаны из исходных PDF.
